## 1. 产品定位

### 1.1 产品名称
**悦己颜值社**

### 1.2 产品定义
「悦己颜值社」是一款面向女性用户的美学生活方式平台，旨在帮助用户通过科学的方法实现自我提升与变美。平台整合了AI分析、个性化推荐、社交互动等功能，打造全方位的变美体验。

### 1.3 核心价值主张
- **科学变美**：基于AI技术的面部特征与肤质分析，提供科学依据
- **个性化计划**：根据用户特征定制专属变美计划
- **社区互动**：分享变美心得，建立积极的社交氛围
- **可持续美学**：倡导健康、可持续的变美理念

### 1.4 产品边界
- **核心业务**：美学生活方式服务（分析、推荐、内容、社交）、会员订阅与积分充值支付
- **非核心业务**：实物电商、医疗服务

## 5. 各模块功能详细需求

### 5.1 模块一：变美分析（P0）

#### 5.1.1 功能概述
基于AI技术对用户面部特征和肤质进行科学分析，生成个性化分析报告。支持多角度照片上传以提高分析准确性。

#### 5.1.2 详细功能点

| 功能点 | 描述 | 需求来源 |
|-------|------|---------|
| 多角度照片上传 | 支持上传正脸（必需）、左脸（推荐）、右脸（推荐）、俯视（选填）、仰视（选填）、全身（推荐）照片 | 提高分析准确性 |
| 面部特征分析 | 分析五官比例、脸型、肤色等特征 | 科学变美基础 |
| 肤质检测 | 检测肤质类型、毛孔、色斑、黑眼圈等问题 | 用户核心需求 |
| 皮肤状态观察 | 观察皮肤泛红凸起、皮肤纹理、毛孔可见度等状态 | 用户需求 |
| 体态观察 | 分析身材类型、头肩比、腿身比、体态习惯 | 用户需求 |
| 分析报告生成 | 生成详细的分析报告，包含改善建议 | 提供价值输出 |
| 历史记录 | 保存多次分析记录，支持对比查看 | 追踪变化 |
| 隐私模式选择 | 支持严格模式（端侧处理）/标准模式（服务端处理） | 用户隐私保护需求 |
| 生活方式问卷 | 用户填写生活方式相关问卷，为分析提供更多维度数据 | 多维度分析需求 |
| 端侧AI处理 | 支持在用户设备端进行AI分析，保护用户隐私 | 隐私保护需求 |
| 报告标签式导航 | 报告采用标签式导航，分为面部形体分析、妆容、穿搭、发型、美容美体五个功能区 | 用户需求 |
| 妆容推荐 | 每条推荐包含详细描述和查看效果图按钮 | 用户需求 |
| 穿搭推荐 | 每条推荐包含详细描述、搭配发型建议和查看效果图按钮 | 用户需求 |
| 发型推荐 | 每条推荐包含详细描述、与理发师沟通话术和查看效果图按钮 | 用户需求 |
| 美容美体周期计划 | 分三个周期，每个周期包含解决问题和目标，提供查看当前周期计划按钮 | 用户需求 |
| 当场生成报告一致性 | 上传照片后当场生成的报告与个人中心我的报告内容一致 | 用户需求 |
| 拍摄引导页 | 半透明人脸轮廓线框辅助定位，实时检测光线不足/画面模糊/脸部未对准/检测到眼镜并给出提示。底部按钮"拍照"或"从相册选择"。底部文案："这张照片仅用于AI分析，不会被人浏览" | 用户体验优化 |
| 分析进度动画 | 动画进度环+文字轮播（4条循环显示，每条3秒）："正在分析你的脸型特征..."、"正在分析你的肤色色调..."、"正在分析你的身材比例..."、"正在生成你的专属分析报告..." | 用户体验优化 |
| 分析结果页结构 | 完整展示：脸型、肤色、三庭比例、五官特征、眼距、身材类型、肩臀比、体态观察、皮肤状态观察(T区/两颊/鼻翼/眼周/下巴等区域)、风格标签。底部固定文案："以上为AI对你当前状态的美学分析，不是医学诊断" | 用户需求 |

#### 5.1.3 交互流程
1. 用户点击"开始分析"
2. 上传多角度照片（正脸必需，其他角度推荐）
3. AI进行分析处理（显示加载动画）
4. 生成完整分析报告（标签式导航）
5. 用户查看报告各功能区详情
6. 点击查看效果图跳转到姿造美学对应功能区

#### 5.2.1 功能概述
根据用户特征提供个性化的造型推荐和穿搭指导，包含妆容、穿搭、发型、美容美体四个子模块。

#### 5.2.2 详细功能点

| 功能点 | 描述 | 需求来源 |
|-------|------|---------|
| 风格测试 | 通过问卷测试用户风格偏好 | 了解用户喜好 |
| 造型推荐 | 根据分析结果推荐适合的发型、妆容 | 个性化计划 |
| 穿搭指导 | 根据体型和风格推荐服装搭配 | 形象管理需求 |
| 虚拟试妆 | 支持虚拟试妆功能，预览效果 | 提升体验 |
| 收藏夹 | 用户收藏喜欢的造型计划 | 便于查看 |
| 效果图缓存策略 | 后端根据user_id+category+plan_number+color_variant+generation_params生成cache_key，相同请求直接返回已有图片URL，不重复生成、不重复扣积分 | 性能优化 |
| 效果图质量保障 | 面部融合度指标SSIM≥0.85为合格，不合格自动重试最多3次，3次仍不合格退回积分并提示"建议重新拍摄标准照" | 质量保障 |
| 换颜色功能 | 颜色映射预览+真正生图两种模式 | 用户个性化需求 |
| 专属美妆课程自动生成 | 课程生成必须遵循6步固定骨架（妆前准备→底妆→眉眼→修容与腮红→唇妆→定妆检查），不允许LLM自行增减步骤。每步必须包含"为什么这么做"的原因说明和至少一条针对用户个人特征的个性化Tip。课程完成后弹出评分"这节课对你有用吗？"（👍/👎） | 教育内容需求 |
| 预设素材库 | 所有预设素材（穿搭搭配套装图、发型轮廓图、妆容局部示意图）均为AI生成，不出现任何真人。素材规格：PNG或JPEG，分辨率1024×1024。穿搭图Prompt模板："电商白底图，一套[场景描述]穿搭，[具体单品描述]，无脸虚拟人台穿着，无真人，无真实皮肤，纯白背景，高清"。发型图Prompt模板："理发店白色人台模型，[发型描述]，[颜色]，前侧后三视角，无真实人脸，纯浅灰背景，高清" | 内容质量需求 |
| 积分消耗确认弹窗 | 每次点击生成效果图前必须弹窗确认，显示：本次消耗积分数、当前剩余积分、会员消耗积分对比、"同方案同参数不重复扣积分"提示、[确认生成]和[成为会员立省]两个按钮 | 用户体验优化 |
| 效果图加载状态 | 生成中显示骨架屏（灰色占位图+呼吸动画）+文字"正在为你生成效果图，预计需要5-15秒" | 用户体验优化 |
| 效果图失败兜底 | 失败时显示占位图（灰色+刷新图标）+文字"生成失败，请重试"+[重新生成]按钮（不扣积分）。三次重试失败后自动退回积分，提示"建议重新拍摄标准照" | 用户体验优化 |
| 效果图反馈 | 每张效果图下方显示"效果像吗？"（👍/👎）。👎超过30%的效果图进入人工审核队列。用户连续3次👎弹出引导"是否重新拍摄标准照" | 质量反馈 |

### 5.9 模块九：风控系统（P0）

#### 5.9.1 功能概述
风控系统是平台的安全基础设施，提供多层防御体系和事后审计机制。

#### 5.9.2 详细功能点

| 功能点 | 描述 | 需求来源 |
|-------|------|---------|
| 设备指纹 | 识别用户设备特征，防止多账号操作 | 安全需求 |
| 手机号验证 | 用户注册和关键操作时进行手机号验证 | 账号安全 |
| 照片相似度检测 | 检测用户上传照片的相似度，防止作弊 | 内容安全 |
| 行为真实度评分-无照片上传 | -30分：注册后未上传任何分析照片 | 风控需求 |
| 行为真实度评分-照片为网图/重复 | -40分：上传照片经pHash检测与已有照片或网图库高度相似 | 风控需求 |
| 行为真实度评分-操作时长过短 | -20分：从注册到完成首次分析<30秒 | 风控需求 |
| 行为真实度评分-首次后7天未再打开 | -50分：首次使用后7天内无任何后续操作 | 风控需求 |
| 行为真实度评分-连续打卡3天以上 | +20分：连续3天完成打卡 | 风控需求 |
| 行为真实度评分-上传2张以上不同照片 | +15分：上传了不同时间拍摄的多张照片 | 风控需求 |
| 行为真实度评分-分享好友完成注册 | +25分：分享链接被好友点击且好友完成首次分析 | 风控需求 |
| 行为真实度评分-应用规则 | 分数<30：限制部分免费权益；分数<0：冻结免费权益，需联系客服解冻；每月重新计算一次 | 风控需求 |
| 动态验证 | 根据风险等级触发不同强度的验证机制 | 安全需求 |
| 支付验证 | 支付操作时进行额外验证 | 交易安全 |
| 延时发放 | 奖励发放设置延时，防止欺诈 | 风控需求 |
| 事后审计机制 | 定期审计和回溯分析 | 合规需求 |
